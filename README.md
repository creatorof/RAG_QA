# Recipe Finder
A basic conversational chatbot to find recipes powered by LangChain, ChromaDB, Streamlit, and Ollama. This chatbot can answer user FAQs about recipe information.
## Installation

1. **Clone the repository**


```bash
git clone git@github.com:creatorof/RAG_QA.git
cd faq-chatbot
```


2. **Create a virtual environment**


```bash
python -m venv venv
venv\Scripts\activate
```

3. **Install dependencies**


```bash
pip install -r requirements.txt
```


## Running the chatbot


```bash
streamlit run index.py
```
